# Личный ритм

Веб-приложение для плана тренировок, рецептов, отметок о выполнении, воды и динамики веса. Работает в браузере на телефоне и компьютере; Expo для использования приложения не нужен.

## Где размещаются части приложения

- **Интерфейс:** GitHub Pages — `https://olkosarau.github.io/workout-app/`.
- **API и база данных:** Replit. Pages хранит только статические файлы сайта; аккаунты и журнал тренировок остаются в API и PostgreSQL.
- **Установка на телефон:** откройте сайт в Safari или Chrome и выберите «На экран Домой» / «Установить приложение». Для синхронизации данных устройству нужен интернет.

Репозиторий публичный: здесь находится исходный код, но не пароли, токены пользователей или их журнал.

## Первичная настройка публикации

1. Опубликуйте Replit-проект, чтобы у API появился постоянный HTTPS-адрес. Используйте адрес корня сайта, без `/api` в конце.
2. В GitHub откройте **Settings → Pages** и выберите **GitHub Actions** в качестве источника публикации.
3. Откройте **Settings → Secrets and variables → Actions → Variables** и добавьте переменную репозитория:
   - имя: `VITE_API_BASE_URL`
   - значение: HTTPS-адрес опубликованного Replit-проекта, например `https://<ваш-домен-replit>`
4. Запустите **Actions → Deploy GitHub Pages → Run workflow**. Дальше сайт будет автоматически пересобираться после изменений в `main`.

Переменная `VITE_API_BASE_URL` не является секретом: это публичный адрес API, который попадёт в собранный JavaScript. Не указывайте в ней пароль, токен или URL с учётными данными.

API разрешает запросы с `https://olkosarau.github.io`. Если подключите собственный домен GitHub Pages, добавьте его в переменную Replit `CORS_ALLOWED_ORIGINS` и оставьте там также `https://olkosarau.github.io`.

## Локальная разработка

В Replit запущены два сервиса: веб-приложение и API. Схема базы разработки применяется командой:

```sh
pnpm --filter @workspace/db run push
```

Для сборки интерфейса задайте `PORT` и `BASE_PATH`; GitHub Actions уже использует `PORT=4173` и `BASE_PATH=/workout-app/`.

## Важное о старых данных

Старая локальная база из Expo/SQLite не входит в репозиторий и не переносится автоматически. После запуска центрального API нужно зарегистрировать аккаунт заново; старые отметки, вес и профили останутся на прежнем устройстве, пока их отдельно не экспортировать.
